# Chinese Structure Lab — A1/A2 Foundation Curriculum

Status: active curriculum architecture

## Mission

A1/A2 are not a small prelude to "real Chinese". They are where the learner builds the perceptual and structural foundation of Mandarin.

The goal is not to memorize sentence lists. The learner should gradually begin to perceive:

Mental Scene → Sound → Word/Chunk → Pinyin → Meaning → Hanzi → Sentence → Structure → Reencounter

## UI rule for A1/A2

Initial presentation should not begin with a fully visible Chinese sentence.

1. Mental Scene Trigger (optional emoji; clue, not translation)
2. meaningful-unit buttons as `?`
3. first tap: audio only
4. second tap: Hanyu Pinyin
5. third tap: English meaning
6. fourth tap: Japanese meaning
7. fifth/deeper tap: Hanzi + accumulated detail
8. separate sentence button follows audio → pinyin → English → Japanese → Hanzi + structure

Button unit is a lexical or pedagogically meaningful unit, never mechanically one Hanzi = one button.

Examples:
- 洗手间 = one lexical button
- 没关系 = one chunk
- 桌子上 = one location chunk when useful
- 三个人 = one counting chunk when the learning target is number + measure + noun
- 吃过 may later open into 吃 + 过

## Mental Scene Trigger

Emoji is optional. It should suggest situation, intention, emotion or consequence without directly encoding every word.

Good: `🚶😟🚻❓` for a restroom-location question.
Bad: one emoji mechanically attached to every vocabulary item.

Primary effect: curiosity without anxiety — “What might this mean?”

# A1 Foundation Architecture

Internal target: 500–700 curated encounters, not 500–700 unrelated sentences.

## A1-0 Sound foundation
- four lexical tones in real words
- neutral tone
- third-tone sandhi
- 一 tone changes
- 不 tone change
- common initials/finals contrasts
- syllable boundaries
- hearing before analysis

## A1-1 People and identity
- 我 / 你 / 他 / 她 / 我们 / 你们 / 他们
- 是 / 不是
- 叫 / 姓
- 人 / 朋友 / 老师 / 学生 / 同事 / 家人
- nationality, language, occupation

## A1-2 Existence, possession, location
- 有 / 没有
- 在
- 这里 / 那里 / 哪儿
- 上 / 下 / 里 / 外 / 前 / 后 / 左 / 右 / 旁边
- 有 vs 在 through repeated contrastive scenes

## A1-3 Core actions
- 吃 / 喝 / 去 / 来 / 回 / 看 / 听 / 说 / 学 / 做 / 买 / 给 / 找 / 等 / 坐 / 开 / 住 / 工作 / 学习
- SVO as a tendency, not a memorized formula
- serial actions in ordinary scenes

## A1-4 Wants, ability, permission
- 想 / 要 / 喜欢
- 会 / 能 / 可以
- 不想 / 不要 / 不会 / 不能 / 不可以
- semantic contrast through scenes

## A1-5 Questions
- 吗 / 呢
- 什么 / 谁 / 哪 / 哪儿 / 几 / 多少 / 怎么 / 为什么 / 什么时候
- question word remains in the information slot
- A-not-A recognition later in A1

## A1-6 Negation
- 不 for habits/general/future/volition
- 没 / 没有 for non-occurrence/existence
- 还没
- 别 / 不要 as basic prohibition/request

## A1-7 Description
- 很 + adjective
- 不太
- 太…了
- 真…
- 有点儿
- 大小冷热快慢远近贵便宜
- adjective predicates without forcing 是

## A1-8 Time and routine
- today/yesterday/tomorrow
- days of week/date
- clock time
- morning/noon/afternoon/evening
- 每天 / 常常 / 有时候
- time before action

## A1-9 Number and measure
- 0–1000 recognition and production
- 二 vs 两
- 个 / 本 / 杯 / 碗 / 张 / 件 / 位 / 口 / 条 / 瓶 / 块
- price, age, phone numbers, dates, quantities

## A1-10 Possession and modification
- 的
- close relations without 的
- 这/那 + measure + noun
- 哪 + measure + noun
- simple adjective + 的 + noun

## A1-11 Daily worlds
- waking and home
- eating and drinking
- school/work
- shopping
- transport
- restaurant
- family/friends
- weather/clothes
- simple health/service situations

## A1-12 Communication repair
- 对不起 / 没关系
- 谢谢 / 不客气
- 我不明白
- 请再说一遍
- 请说慢一点
- 这个怎么说？
- 这是什么意思？
- 我听不懂 / 我看不懂 as late A1 recognition

## A1 reencounter rule
Every core construction should appear across at least three different worlds before it is treated as familiar.

Example: 在
- 我在家。
- 咖啡店在车站旁边。
- 你在哪儿工作？
- 手机在包里。
- 我们在门口见。

# A2 Foundation Architecture

Internal target: 500–700 curated encounters.

A2 should not feel like a list of new grammar points. It should recombine A1 language into connected events, explanations and small narratives.

## A2-1 Event state and aspect
- sentence-final 了
- verb + 了
- 过 experience
- 正在 / 在 … 呢
- 着 recognition and common use
- 还没 / 已经…了
- aspect contrasts through the same event

## A2-2 Result complements
- 吃完 / 做完 / 看完
- 听懂 / 看懂
- 找到 / 买到
- 写好 / 准备好
- 说错 / 坐错
- 打开 / 关上

## A2-3 Direction and motion
- 来 / 去
- 进来 / 进去
- 出来 / 出去
- 回来 / 回去
- 上来 / 上去 / 下来 / 下去
- 拿来 / 带去 / 走进去 in natural scenes

## A2-4 Degree and manner
- V + 得 + adjective/complement
- adjective + 一点儿
- 更 / 最 / 比较
- 比
- 没有…那么…
- 越来越…

## A2-5 Sequence and time relations
- 先…再…
- …以后 / …以前
- …的时候
- 一…就…
- 刚…就…
- 已经…才… later recognition

## A2-6 Reason, condition, contrast
- 因为…所以…
- 如果…就…
- 虽然…但是…
- 可是 / 不过
- 还是 / 或者

## A2-7 Plans, intention, obligation
- 打算 / 决定 / 准备
- 应该 / 得 / 需要
- 可能 / 也许
- 能不能 / 可不可以

## A2-8 Comparison and choice
- 比 / 更 / 最 / 一样 / 不一样
- 还是 / 或者
- 哪个更…
- A 没有 B 那么…

## A2-9 Connected noun phrases
- 的 as nominalizer
- simple relative modification
- 我买的书
- 昨天认识的人
- 你说的那个地方

## A2-10 把 entry
Teach only where the affected object and resulting state are clear.
- 把门打开
- 把书放在桌子上
- 把名字写在这里
- 把票给我

## A2-11 被 recognition / basic use
Do not overproduce textbook passives.
- 我的自行车被人骑走了
- 手机被我忘在酒店了 (also compare more natural active alternatives)
- culturally/naturally preferred active formulations should be shown when better

## A2-12 Connected everyday discourse
- invitations
- changing plans
- travel problem → repair
- shopping comparison → decision
- work/study explanation
- health/service dialogue
- short personal story
- describing change over time
- giving a reason and consequence
- asking for clarification and confirming understanding

## A2 reencounter rule
A2 construction should reappear with familiar A1 vocabulary before new vocabulary is layered on top.

# Coverage ledger

For every encounter record:
- level
- situation/world
- communicative intent
- target sound feature if any
- target construction
- reencounter constructions
- lexical units/chunks
- pinyin
- English
- Japanese
- optional Mental Scene Trigger
- deep structure note

## Quality gates

A sentence must pass:
1. grammatical Mandarin
2. idiomatic everyday Mandarin for its scene
3. useful communicative intent
4. level-appropriate new-language load
5. meaningful chunk segmentation
6. accurate pinyin with tone marks
7. faithful English/Japanese meanings
8. non-redundant curriculum contribution OR intentional reencounter
9. emoji does not simply reveal the answer
10. structure can be explained without forcing an English/Japanese grammar template onto Chinese

## Expansion policy

Prefer connected mini-worlds over isolated vocabulary sentences.

A1: situation → sound → chunk → sentence → immediate response
A2: familiar world → event sequence → reason/result → comparison/choice → repair/continuation
